Claude под ключ

За один вечер вы подключите к Claude свой список задач, GitHub, Google Календарь, Google Диск и Telegram. Программировать не придётся: весь код готов, его нужно только скопировать в файлы.

Как это устроено

Сам по себе Claude умеет только разговаривать. Чтобы он мог смотреть ваш календарь или записывать задачи, к нему подключают маленьких помощников, которые называются MCP-серверами. Каждый помощник знает один сервис и умеет делать с ним несколько простых действий. Claude решает, кого из них позвать, а вы разрешаете или запрещаете каждое действие.

1
Хост. Программа, в которой вы общаетесь с Claude. Мы используем Claude Desktop.
2
Клиент и протокол MCP. Встроены в хост, настраивать их не нужно. На каждого помощника приходится своя «линия связи».
3
Сервер. Помощник: файл на Python, который мы создадим. Он сообщает Claude, что умеет, и выполняет просьбы.
4
Локальные данные. Файлы на вашем компьютере. Помощник C хранит задачи в файле tasks.db.
5
Онлайн-сервисы. Google, Telegram, GitHub. Помощники A и B ходят к ним через интернет по вашим ключам доступа.

Мы соберём систему по шагам, от простого к сложному: сначала C, потом B, потом A. После каждого урока система работает, и это можно проверить.

Часть 1. Терминал

Терминал — окно, куда вводят команды. Через него мы будем устанавливать и проверять программы.

Нажмите Пуск, наберите PowerShell и откройте его.

Нажмите ⌘ + Пробел, наберите Терминал и откройте его.

Команды со страницы вставляйте в терминал целиком и нажимайте Enter. Если в описании сказано «откройте терминал заново», закройте окно и откройте новое: только так терминал узнает о только что установленной программе.

Часть 2. Python

  1. Скачайте установщик

    Откройте python.org/downloads/windows. В списке найдите последнюю версию Python 3.13 и нажмите Windows installer (64-bit).

  2. Отметьте «Add python.exe to PATH»

    Запустите скачанный файл. Внизу первого окна поставьте галочку Add python.exe to PATH. Это самый важный шаг: без галочки терминал не найдёт Python. Затем нажмите Install Now.

  3. Снимите ограничение длины путей

    Если в конце установки появится кнопка Disable path length limit, нажмите её. Затем Close.

  4. Проверьте

    Откройте PowerShell заново и выполните:

    PowerShell
    python --version

    Ответ должен быть вида Python 3.13.9. Если вместо этого открылся Microsoft Store, загляните в раздел «Если не работает».

  1. Скачайте установщик

    Откройте python.org/downloads/macos. В списке найдите последнюю версию Python 3.13 и нажмите macOS 64-bit universal2 installer.

  2. Установите

    Откройте скачанный файл .pkg и нажимайте Продолжить, затем Установить. macOS попросит пароль от компьютера.

  3. Установите сертификаты

    В Finder откройте Программы → Python 3.13 и дважды щёлкните файл Install Certificates.command. Откроется терминал, дождитесь слова completed. Без этого шага Python не сможет подключаться к Google и Telegram.

  4. Проверьте

    Откройте Терминал заново и выполните:

    Терминал
    python3 --version

    Ответ должен быть вида Python 3.13.9. На Mac команда пишется с тройкой: python3.

Часть 3. uv

uv скачивает библиотеки, которые нужны помощникам (например, для связи с Google), и запускает помощников. Он сам найдёт установленный Python.

  1. Установите uv

    PowerShell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    Терминал
    curl -LsSf https://astral.sh/uv/install.sh | sh

    Когда установка закончится, откройте терминал заново.

  2. Проверьте и запишите адрес uv

    PowerShell
    uv --version
uv python find
where.exe uv
    Терминал
    uv --version
uv python find
which uv

    Первая строка ответа покажет версию uv. Вторая покажет, какой Python он нашёл: в адресе должно быть Python313 или 3.13. Третья покажет полный адрес uv, например C:\Users\Anna\.local\bin\uv.exe/Users/anna/.local/bin/uv. Скопируйте его в заметки, он понадобится в каждом уроке.

Часть 4. База данных

Задачи будут храниться в базе данных SQLite. Это не отдельная программа-сервер, которую нужно запускать и настраивать. Вся база — один файл tasks.db, а умение с ним работать уже встроено в Python. Поэтому устанавливать саму базу не нужно, достаточно убедиться, что она на месте.

  1. Проверьте SQLite

    PowerShell
    python -c "import sqlite3; print('SQLite', sqlite3.sqlite_version)"
    Терминал
    python3 -c "import sqlite3; print('SQLite', sqlite3.sqlite_version)"

    Ответ вида SQLite 3.49.1 значит, что всё в порядке. Сам файл базы помощник создаст при первой задаче в уроке 2.

  2. Установите DB Browser for SQLite

    Это бесплатная программа, чтобы смотреть содержимое базы как таблицу. Скачайте её с sqlitebrowser.org/dl.

    Выберите Standard installer for 64-bit Windows, запустите и нажимайте Next до конца.

    Выберите версию для macOS (Universal), откройте файл .dmg и перетащите DB Browser в папку «Программы». Если при первом запуске macOS скажет, что разработчик не проверен, нажмите на программу правой кнопкой и выберите Открыть.

А если нужна «настоящая» база?

Для личного помощника SQLite хватает с запасом: она спокойно хранит миллионы записей. Серверные базы вроде PostgreSQL нужны, когда с данными одновременно работает много людей.

Урок 2Сервер C20 минут

Задачи на компьютере

Первый помощник ведёт список задач. Он хранит его в файле tasks.db рядом с собой, интернет ему не нужен. На этом уроке вы пройдёте весь путь подключения, а дальше он будет повторяться.

  1. Создайте файл tasks.py

    В VS Code нажмите File → New File, назовите файл tasks.py, вставьте код и сохраните (Ctrl⌘ + S).

    tasks.py
    # /// script
# dependencies = ["mcp"]
# requires-python = ">=3.12"
# ///
import sqlite3
from pathlib import Path
from mcp.server.fastmcp import FastMCP

DB = Path(__file__).with_name("tasks.db")
mcp = FastMCP("Задачи")


def db():
    con = sqlite3.connect(DB)
    con.row_factory = sqlite3.Row
    con.execute("""CREATE TABLE IF NOT EXISTS tasks (
        id INTEGER PRIMARY KEY,
        title TEXT NOT NULL,
        due TEXT,
        done INTEGER NOT NULL DEFAULT 0)""")
    return con


@mcp.tool()
def add_task(title: str, due: str = "") -> str:
    """Добавить задачу. due — срок в формате ГГГГ-ММ-ДД, можно оставить пустым."""
    with db() as con:
        cur = con.execute("INSERT INTO tasks (title, due) VALUES (?, ?)", (title, due or None))
    return f"Задача #{cur.lastrowid} добавлена"


@mcp.tool()
def list_tasks(include_done: bool = False) -> list[dict]:
    """Список задач. По умолчанию только невыполненные, ближайшие сроки сверху."""
    where = "" if include_done else " WHERE done = 0"
    with db() as con:
        rows = con.execute("SELECT * FROM tasks" + where + " ORDER BY due IS NULL, due")
        return [dict(r) for r in rows]


@mcp.tool()
def complete_task(task_id: int) -> str:
    """Отметить задачу выполненной по её номеру."""
    with db() as con:
        changed = con.execute("UPDATE tasks SET done = 1 WHERE id = ?", (task_id,)).rowcount
    return "Готово" if changed else f"Задачи #{task_id} нет"


if __name__ == "__main__":
    mcp.run()

    Разбираться в коде не обязательно, но устроен он просто. Каждая функция с пометкой @mcp.tool() становится инструментом, который увидит Claude. Текст в тройных кавычках подсказывает Claude, когда этот инструмент нужен.

  2. Запустите помощника один раз вручную

    При первом запуске uv скачивает библиотеку mcp. Это занимает до минуты, и Claude может не дождаться. Поэтому первый запуск делаем сами:

    PowerShell
    uv run C:\mcp\tasks.py
    Терминал
    uv run ~/mcp/tasks.py

    Когда загрузка закончится, терминал замолчит. Так и должно быть: помощник ждёт, когда к нему обратится Claude. Остановите его клавишами Ctrl + C.

  3. Пропишите помощника в настройках Claude

    В Claude Desktop откройте Settings → Developer → Edit Config (в русском интерфейсе Настройки → Разработчик). Откроется файл claude_desktop_config.json. Замените всё его содержимое на это:

    claude_desktop_config.json
    {
  "mcpServers": {
    "tasks": {
      "command": "C:\\Users\\ИМЯ\\.local\\bin\\uv.exe",
      "args": ["run", "C:\\mcp\\tasks.py"]
    }
  }
}
    claude_desktop_config.json
    {
  "mcpServers": {
    "tasks": {
      "command": "/Users/ИМЯ/.local/bin/uv",
      "args": ["run", "/Users/ИМЯ/mcp/tasks.py"]
    }
  }
}

    В строке command укажите адрес uv, который вы записали в уроке 1. Обратите внимание: в этом файле каждая обратная косая черта пишется дважды, \\. Вместо ИМЯ подставьте имя пользователя, оно есть в том же адресе. Сохраните файл.

  4. Полностью перезапустите Claude

    Закрыть окно недостаточно. Найдите значок Claude возле часов в правом нижнем углу, нажмите на него правой кнопкой и выберите Quit. Затем откройте Claude снова.

    Нажмите ⌘ + Q, чтобы Claude закрылся полностью, и откройте его снова.

  5. Попросите Claude поработать с задачами

    • Добавь задачу «Купить билеты в Казань» на 25 октября
    • Добавь задачу «Позвонить в банк» на завтра
    • Какие у меня задачи?

    Перед первым действием Claude спросит разрешения на инструмент add_task. Так работает защита: без вашего согласия помощник ничего не сделает. Нажмите «Разрешить».

  6. Загляните в базу данных

    Откройте DB Browser for SQLite, нажмите Open Database и выберите файл C:\mcp\tasks.dbtasks.db в папке mcp. На вкладке Browse Data выберите таблицу tasks: там будут ваши задачи. Колонка done показывает, выполнена ли задача (1) или нет (0).

    Если вы что-то поменяли в таблице руками, нажмите Write Changes. Пока изменения не сохранены, база занята, и Claude не сможет в неё записывать. Закончив, закройте DB Browser.

Проверка

Claude показывает список из двух задач со сроками, и те же задачи видны в DB Browser.

Урок 3Сервер B20 минут

GitHub

Второй помощник работает с онлайн-сервисом. Мы взяли GitHub, где команды ведут задачи по проектам. Если вы им не пользуетесь, урок можно пропустить: любой другой сервис подключается так же, через ключ доступа и пару функций.

  1. Получите ключ доступа (токен)

    На github.com нажмите на свой аватар и откройте Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Заполните:

    • Token name: Claude
    • Expiration: 90 days
    • Repository access: Only select repositories, выберите один репозиторий
    • Permissions → Issues: Read and write

    Нажмите Generate token и сразу скопируйте токен в заметки: GitHub покажет его только один раз.

    Важно

    Токен работает как пароль. Не пересылайте его и не публикуйте на скриншотах.

  2. Создайте файл github.py

    github.py
    # /// script
# dependencies = ["mcp", "httpx"]
# requires-python = ">=3.12"
# ///
import os
import httpx
from mcp.server.fastmcp import FastMCP

REPO = os.environ["GITHUB_REPO"]
gh = httpx.Client(
    base_url="https://api.github.com",
    headers={
        "Authorization": f"Bearer {os.environ['GITHUB_TOKEN']}",
        "Accept": "application/vnd.github+json",
    },
    timeout=30,
)
mcp = FastMCP("GitHub")


@mcp.tool()
def list_issues(state: str = "open") -> list[dict]:
    """Список issues в репозитории. state: open, closed или all."""
    r = gh.get(f"/repos/{REPO}/issues", params={"state": state, "per_page": 30})
    r.raise_for_status()
    return [
        {"number": i["number"], "title": i["title"], "state": i["state"], "url": i["html_url"]}
        for i in r.json()
        if "pull_request" not in i
    ]


@mcp.tool()
def create_issue(title: str, body: str = "") -> str:
    """Создать issue в репозитории. Возвращает ссылку на него."""
    r = gh.post(f"/repos/{REPO}/issues", json={"title": title, "body": body})
    r.raise_for_status()
    return r.json()["html_url"]


if __name__ == "__main__":
    mcp.run()

    Токен и название репозитория не записаны в коде. Помощник получит их из настроек Claude, поэтому файлом можно делиться без риска.

  3. Запустите один раз вручную

    PowerShell
    $env:GITHUB_TOKEN="x"; $env:GITHUB_REPO="x"; uv run C:\mcp\github.py
    Терминал
    GITHUB_TOKEN=x GITHUB_REPO=x uv run ~/mcp/github.py

    Здесь подставлены временные значения, нам нужна только загрузка библиотек. Дождитесь тишины и нажмите Ctrl + C.

  4. Обновите настройки Claude

    Снова откройте Settings → Developer → Edit Config и замените содержимое целиком:

    claude_desktop_config.json
    {
  "mcpServers": {
    "tasks": {
      "command": "C:\\Users\\ИМЯ\\.local\\bin\\uv.exe",
      "args": ["run", "C:\\mcp\\tasks.py"]
    },
    "github": {
      "command": "C:\\Users\\ИМЯ\\.local\\bin\\uv.exe",
      "args": ["run", "C:\\mcp\\github.py"],
      "env": {
        "GITHUB_TOKEN": "github_pat_ВАШ_ТОКЕН",
        "GITHUB_REPO": "ваш-логин/название-репозитория"
      }
    }
  }
}
    claude_desktop_config.json
    {
  "mcpServers": {
    "tasks": {
      "command": "/Users/ИМЯ/.local/bin/uv",
      "args": ["run", "/Users/ИМЯ/mcp/tasks.py"]
    },
    "github": {
      "command": "/Users/ИМЯ/.local/bin/uv",
      "args": ["run", "/Users/ИМЯ/mcp/github.py"],
      "env": {
        "GITHUB_TOKEN": "github_pat_ВАШ_ТОКЕН",
        "GITHUB_REPO": "ваш-логин/название-репозитория"
      }
    }
  }
}

    Название репозитория берётся из его адреса: для github.com/anna/site это anna/site. Сохраните файл и полностью перезапустите Claude, как в уроке 2.

  5. Проверьте

    • Какие открытые issues в моём репозитории?
    • Создай issue «Обновить контакты на сайте» с описанием: новый телефон офиса
Проверка

Claude прислал ссылку на новый issue, и он открывается на GitHub.

Урок 4Сервер A45 минут

Telegram, Календарь и Диск

Самый полезный помощник: он смотрит и создаёт события в Google Календаре, ищет файлы на Google Диске и присылает вам сообщения в Telegram. Ему нужны два ключа: от Telegram-бота и от Google. Это самый длинный урок, зато дальше всё будет просто.

Часть 1. Бот в Telegram

  1. Создайте бота

    Найдите в Telegram @BotFather, отправьте ему /newbot, придумайте название и имя, которое заканчивается на bot. В ответ придёт токен вида 7412345678:AAH.... Сохраните его в заметки.

  2. Напишите своему боту

    Откройте бота по ссылке от BotFather, нажмите Start и отправьте любое сообщение. Без этого бот не сможет писать вам первым.

  3. Узнайте номер своего чата

    Откройте в браузере адрес ниже, подставив свой токен:

    Адрес в браузере
    https://api.telegram.org/botВАШ_ТОКЕН/getUpdates

    Найдите на странице фрагмент "chat":{"id":123456789. Это число и есть номер чата. Сохраните его.

Часть 2. Доступ к Google

Google выдаёт доступ к Календарю и Диску только «приложениям», поэтому мы зарегистрируем своё маленькое приложение. Это бесплатно.

  1. Создайте проект

    Откройте console.cloud.google.com, войдите под своим Google-аккаунтом и создайте проект с названием «Claude помощник».

  2. Включите Календарь и Диск

    В меню слева выберите APIs & Services → Library. Найдите Google Calendar API и нажмите Enable. Затем так же включите Google Drive API.

  3. Опишите приложение

    Откройте Google Auth Platform (в старом интерфейсе OAuth consent screen) и нажмите Get started. Название: «Claude помощник», почта: ваша, Audience: External. Завершите мастер.

  4. Добавьте себя в тестировщики

    В разделе Audience найдите Test users → Add users и впишите свой Gmail. Без этого Google не пустит вас в собственное приложение.

  5. Скачайте ключ

  1. Создайте файл internet.py

    internet.py
    # /// script
# dependencies = ["mcp", "httpx", "google-api-python-client", "google-auth-oauthlib"]
# requires-python = ">=3.12"
# ///
import os
import sys
from datetime import datetime, timedelta
from pathlib import Path

import httpx
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build
from mcp.server.fastmcp import FastMCP

HERE = Path(__file__).parent
TOKEN = HERE / "google_token.json"
SCOPES = [
    "https://www.googleapis.com/auth/calendar.events",
    "https://www.googleapis.com/auth/drive.readonly",
]
mcp = FastMCP("Интернет")


def google(service, version):
    if not TOKEN.exists():
        raise RuntimeError("Нет входа в Google. Выполните в терминале: uv run internet.py login")
    creds = Credentials.from_authorized_user_file(str(TOKEN), SCOPES)
    if not creds.valid:
        creds.refresh(Request())
        TOKEN.write_text(creds.to_json())
    return build(service, version, credentials=creds)


@mcp.tool()
def upcoming_events(days: int = 7) -> list[dict]:
    """События из Google Календаря на ближайшие дни."""
    now = datetime.now().astimezone()
    items = google("calendar", "v3").events().list(
        calendarId="primary",
        timeMin=now.isoformat(),
        timeMax=(now + timedelta(days=days)).isoformat(),
        singleEvents=True,
        orderBy="startTime",
    ).execute().get("items", [])
    return [
        {"title": e.get("summary", ""), "start": e["start"].get("dateTime", e["start"].get("date"))}
        for e in items
    ]


@mcp.tool()
def create_event(title: str, start: str, minutes: int = 60) -> str:
    """Создать событие в Google Календаре. start — дата и время, например 2026-10-20T15:00."""
    begin = datetime.fromisoformat(start).astimezone()
    event = {
        "summary": title,
        "start": {"dateTime": begin.isoformat()},
        "end": {"dateTime": (begin + timedelta(minutes=minutes)).isoformat()},
    }
    return google("calendar", "v3").events().insert(calendarId="primary", body=event).execute()["htmlLink"]


@mcp.tool()
def search_drive(text: str) -> list[dict]:
    """Найти файлы на Google Диске по словам в названии или тексте."""
    safe = text.replace("\\", "\\\\").replace("'", "\\'")
    return google("drive", "v3").files().list(
        q=f"fullText contains '{safe}' and trashed = false",
        pageSize=10,
        fields="files(name, webViewLink, modifiedTime)",
    ).execute()["files"]


@mcp.tool()
def send_telegram(text: str) -> str:
    """Отправить сообщение владельцу в Telegram."""
    r = httpx.post(
        f"https://api.telegram.org/bot{os.environ['TELEGRAM_TOKEN']}/sendMessage",
        json={"chat_id": os.environ["TELEGRAM_CHAT_ID"], "text": text},
        timeout=30,
    )
    r.raise_for_status()
    return "Отправлено"


if __name__ == "__main__":
    if sys.argv[1:] == ["login"]:
        flow = InstalledAppFlow.from_client_secrets_file(str(HERE / "credentials.json"), SCOPES)
        TOKEN.write_text(flow.run_local_server(port=0).to_json())
        print("Вход выполнен, ключ сохранён в google_token.json")
    else:
        mcp.run()

    Доступ к Диску здесь только на чтение: помощник может искать файлы, но не может их менять или удалять.

Claude сделает примерно так, и на каждый шаг спросит разрешения:

  1. list_tasks получает задачи из файла на компьютере

  3. create_event ставит событие для каждой срочной задачи
  4. send_telegram присылает сводку вам в телефон

Урок 610 минут

Как пользоваться каждый день

Как формулировать просьбы

  • Называйте сервис, если просьба двусмысленная: «в календарь», «в задачи», «в GitHub».
  • Указывайте даты конкретно. «В четверг в 15:00» надёжнее, чем «на днях после обеда».
  • Для больших заданий просите сначала план: «Сначала покажи, что собираешься сделать, а потом жди моего ОК».
  • Проверяйте результат по ссылкам. Помощники возвращают ссылки на события и issues, по ним легко убедиться, что всё создано правильно.

Разрешения

Claude спрашивает разрешение на каждый инструмент. Для чтения (list_tasks, upcoming_events, search_drive) можно выбрать «Разрешать всегда». Для действий, которые что-то меняют или отправляют (create_event, create_issue, send_telegram), лучше разрешать каждый раз отдельно.

Безопасность

  • В файле claude_desktop_config.json и в google_token.json лежат ваши ключи. Никому их не пересылайте.
  • Подключайте только тех помощников, которым доверяете. Помощник работает на вашем компьютере с вашими правами.
  • Текст из интернета, например из файла на Диске или из issue, может содержать скрытые указания для Claude. Если Claude вдруг просит разрешения на действие, о котором вы не просили, нажмите «Запретить».
  • Если ключ утёк, отзовите его: токен GitHub удаляется в настройках GitHub, токен бота меняется командой /revoke у BotFather.

Как научить помощника новому

Попросите Claude дописать функцию. Например: «Вот мой tasks.py, допиши инструмент, который удаляет задачу по номеру». Вставьте ответ в файл, сохраните и перезапустите Claude.
